# NZ Environment Atlas

An interactive map and analysis of seven New Zealand environmental datasets from [LAWA (Land, Air, Water Aotearoa)](https://www.lawa.org.nz/):

- River water quality
- Stream life (macroinvertebrates)
- Lakes
- Groundwater
- Swimming spots
- Air quality
- Estuaries

Each view shows sites on a map with a site panel, National Policy Statement for Freshwater Management (NPS-FM) attribute bands, and ten-year trends.

## Viewing it

The whole app is a single self-contained file, `index.html`. Download it and open it in any modern browser, or view it through GitHub Pages if enabled for this repository.
